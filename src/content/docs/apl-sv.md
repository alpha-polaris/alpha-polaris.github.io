## APL_SVとは

APL_SVは、ALPHA_POLARISが運営する、帯域幅が狭い「ホスティングサービスみたいな何か」です。運営者が携わっているサービスを支えるために、善意で提供している環境です。

## 一般提供はしていません

不特定多数に向けたホスティングサービスではありません。一般向けの利用申し込みや、新規利用者の募集は行っていません。

提供先は、基本的に運営者が携わっているサービスです。このページは一般向けの申し込みを案内するものではなく、APL_SVの位置づけを説明するためのものです。

## 提供内容について

利用できるリソースや提供範囲、運用上の役割分担などは、関係するサービスごとに個別に確認します。一律のプランを案内するものではありません。提供方法は、以下のとおりKomodo経由に限定します。

善意による提供であり、帯域幅やリソースには限りがあります。個別に確認していない性能・可用性・継続的な提供を前提にせず、サービスの運用に必要な条件は、あらかじめ運営者と確認してください。

## 提供方法の制限

APL_SVの提供は、**Komodo経由に限ります**。サービスのデプロイや管理は、運営者が案内するKomodo上で、個別に認められた範囲で行うものとします。

サーバーへの直接のSSHアクセス、OSの管理者権限、仮想マシンや物理サーバーそのものの貸し出しなど、Komodoを介さずに環境を直接管理する形では提供しません。

また、443/80ポートの公開はセキュリティ上Cloudflare経由の接続のみサポートされています (そのほかのアドレスからの接続はブロックされます)。使用する場合はインフラ側での設定が必要なため、事前に相談してください。

## 制限の参考例

以下は、提供範囲を確認するための参考例です。具体的な上限値や許可する操作は、対象サービスごとに運営者と確認してください。

| 項目 | 制限の参考例 |
| --- | --- |
| 操作・管理範囲 | Komodo上で対象サービスに必要な操作のみを許可し、他サービスやホスト全体の管理は対象外とする |
| CPU・メモリ | 利用可能な量を個別に定め、他サービスの稼働を妨げる継続的な高負荷を制限する |
| ストレージ | 保存容量や用途を個別に定め、無制限のファイル保管先としての利用を認めない |
| 通信 | 帯域幅が限られるため、大量配信や大容量ファイルの継続的な転送などを制限する |
| 外部公開 | 公開するポートや接続方法を個別に確認し、任意のポートを自由に公開する形では提供しない |

Komodo経由であっても、すべての機能や操作を利用できるとは限りません。必要な構成や操作が提供範囲に収まるか、利用前に確認してください。

## 既存の提供先からの連絡
